# MarketPulse

> В разработке. Учебный pet-проект для демонстрации event-driven архитектуры на реальных биржевых данных.

## Дисклеймер

Этот проект предназначен исключительно для образовательных и информационных целей. В нём используется публичный API MOEX ISS для получения рыночных данных. Полученные данные предназначены для личного ознакомления и демонстрации технических навыков. Этот проект не предназначен для коммерческого использования, распространения или любой деятельности, приносящей прибыль. Все рыночные данные являются собственностью Московской биржи (MOEX). Для коммерческого использования рыночных данных, пожалуйста, обратитесь к официальному сайту MOEX.

Этот проект не связан с Московской биржей (MOEX) и не одобрен ею.

## ML: предсказание направления цены

Логистическая регрессия на лаговых и скользящих признаках (по одной модели
на тикер), обучается на потоковых данных из `trades` (только `source=live`,
без реплея — разная статистическая природа данных).

Валидация — строго по времени (train = прошлое, test = будущее), без
случайного перемешивания. Модель не предназначена для реальной торговли —
цель здесь в демонстрации end-to-end ML на потоковых данных, а не в
предсказательной силе: метрики близкие к случайным (ROC-AUC ~0.5) для
задачи такого рода ожидаемы и не являются признаком ошибки в реализации.

**Как читать метрики:** при `class_weight='balanced'` и сильном дисбалансе классов (~10-15% "рост") accuracy систематически хуже наивного бейзлайна "всегда предсказывай большинство" — это ожидаемое поведение выбранной стратегии взвешивания, а не признак неработающей модели. Основная метрика — ROC-AUC / PR-AUC, сравнивать PR-AUC с `target_rate_test` как с уровнем "без навыка", а не с 0.5.
